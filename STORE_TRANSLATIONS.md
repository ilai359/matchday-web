# Clubside Football: App Store translations

Paste these into App Store Connect when preparing version 1.1. For each
language: open the version page, click the language menu next to
"English (U.S.)" (top right of "Product Page Information"), add the
language, then paste the fields below. Screenshots are reused from
English automatically, so nothing else is needed.

App Store limits: name 30, subtitle 30, promotional text 170, keywords
100 characters (commas, no spaces), description 4000.

Every description ends by saying the app itself is in English, so nobody
downloads it expecting their own language.
